    Projects

    sitecheck

    Running on my server

    A public service that grades how well a website is protected, from A to F: HTTPS, certificate, security headers and cookies. It runs on my Hetzner server in Docker behind Caddy. Every push to main is tested, built into an image and deployed automatically, and rolls back if the new version fails its health check. A monitor re-checks sites every few hours and posts to Discord when something gets worse.

    Because it sends requests to any address a visitor types in, most of the work went into what it refuses to do: only public hostnames, every redirect re-checked, rate limits, and containers that run without root.

    Python, FastAPI, Docker Compose, Caddy, GitHub Actions, SQLite

    How it all runs

    Everything on this page, sitecheck included, runs on one server I set up and look after myself. Three paths keep it going.

    Ship

    1. git pushto main on GitHub
    2. GitHub Actionslint, tests, Docker smoke test
    3. Container imageghcr.io, tagged by commit
    4. deploy.shhealth check, rolls back on failure

    Serve

    1. Visitorany browser
    2. CaddyHTTPS, security headers
    3. sitecheck appFastAPI in Docker
    4. SQLitecheck history

    Watch

    1. Monitorre-checks sites every 6 hours
    2. Discordalert on a grade drop or expiring certificate
    3. UptimeRobotpings the server every 5 minutes
    4. Status pagepublic uptime history
