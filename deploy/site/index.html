    How it all runs

    1. 01

      Push

      Code goes to main on GitHub. That's the only manual step.

    2. 02

      Test

      GitHub Actions runs the linter, the full test suite on three Python versions and a smoke test of the Docker image.

    3. 03

      Build

      The image is built once, tagged with the commit and pushed to ghcr.io.

    4. 04

      Deploy

      deploy.sh pulls it on my Hetzner server, waits for the health check and rolls back by itself if the new version fails.

    5. 05

      Serve

      Caddy handles HTTPS and security headers in front of the app. Certificates renew on their own.

    6. 06

      Watch

      A monitor re-checks sites every 6 hours and posts to Discord. UptimeRobot pings the server every 5 minutes.
